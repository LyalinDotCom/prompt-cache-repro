## Effective-settings audit clarification during the first seed block

The requested Pi reasoning level is `low`, and inspection of both payloads and Pi source confirms that it is carried through all three adapters. Gemini sends `LOW`. GPT fixes top-level `reasoning.effort` at `medium` but inserts an `input` `configuration_update` item setting effort to `low`. Opus fixes top-level `output_config.effort` at `high` but inserts a system message with `output_config.effort: low`. Those wrapper defaults alone do not establish effective medium/high effort. Record these native in-context configuration items when auditing history. Anthropic uses Pi's explicit moving ephemeral cache breakpoints, whereas Gemini/OpenAI use implicit caching. These native Pi adapter differences limit a provider-only causal interpretation. No requests or outcomes are discarded because of these findings, and the frozen integration remains unchanged.
