# Provider adapter notes

Verified against official documentation on 2026-10-17. The adapters use the installed official `openai`, `@google/genai`, and `@anthropic-ai/sdk` packages against their public API endpoints. Offline tests exercise the real SDK serializers through a mocked HTTP transport; no credentials or live API calls are required for tests.

## Requests and caching

- OpenAI uses Responses with `store: false`, `reasoning.effort: low`, `reasoning.context: all_turns`, encrypted reasoning included, and implicit caching with the current 30-minute TTL. Current GPT-6.1 Sol cache writes use their own rate, 1.25 times ordinary input. `input_tokens` includes both reads and writes: ordinary input is **input − reads − writes**. The exact write field is `usage.input_tokens_details.cache_write_tokens`. Missing read/write counters remain unknown. [Official OpenAI prompt-caching guide](https://developers.openai.com/api/docs/guides/prompt-caching#monitor-cache-performance).
- Gemini uses the documented `models.generateContent` interface. This is distinct from the newer Interactions API and its different usage schema. Argon uses `thinkingLevel: LOW`; deprecated sampling parameters are omitted. Caching is implicit only, with a 4,096-token minimum. Both automatic function calling and automatic continuation are explicitly disabled so one observation represents one HTTP request. [Argon migration and model guide](https://ai.google.dev/gemini-api/docs/generate-content/latest-model), [generateContent API reference](https://ai.google.dev/api/generate-content).
- Anthropic uses Messages, automatic ephemeral caching with a 5-minute TTL, and low effort. Thinking settings are model-specific: Sonnet 5.5 uses `thinking: {type: between_tools}`; Opus 5.5 uses `thinking: {type: adaptive}` because thinking is always on. Both reject forced tool choice, so the agent uses `auto` plus clear tool instructions. Its three input counters are exclusive: **total input = ordinary input + reads + writes**. Unexpected 1-hour writes invalidate normalized usage because the default rate card would be wrong. [Sonnet 5.5 changes](https://platform.claude.com/docs/en/models/sonnet-5-5/whats-new-sonnet-5-5), [Opus 5.5 migration requirements](https://platform.claude.com/docs/en/models/opus-5-5/migration-guide#what-every-request-to-claude-opus-5-5-must-satisfy), [cache-usage accounting](https://platform.claude.com/docs/en/build-with-claude/prompt-caching#tracking-cache-performance).

Billing/account tier labels never select reasoning effort. The benchmark holds effort fixed at low across requests.

## Workload behavior

Replay resends exactly the same SDK request. Append adds deterministic synthetic assistant/user text, independently of generated answers, while preserving earlier message boundaries. Perturb changes its first line on every follow-up and keeps the rest constant. Agent runs an actual native tool loop with one `read_fixture` function and deterministic fixture results of exactly `deltaChars` characters. The tool accepts an empty object and has no network or filesystem access. It returns the same semantic fixture sequence across providers.

Prompt revision **validation-v2** uses a finite benign task for every provider: “This is a read-only benchmark of fictional reference records. Retrieve four fixture chunks using read_fixture. Make exactly one tool call per response with {}. After receiving four tool results, give a one-sentence summary.” A four-request trial measures four tool calls; summarization would occur only after the fourth tool result, beyond that trial. The prior indefinite-loop prompt remains identifiable in older recorded wire payloads. No SDK settings or model selection change with this revision.

Agent history preserves complete native assistant content, including Gemini thought signatures, Anthropic signed/redacted thinking blocks, and OpenAI encrypted reasoning items. A missing call, multiple calls, or truncation stops continuation. No signatures, tool calls, or model responses are invented by the agent scenario. OpenAI/Gemini request a function call; Anthropic's current API requires the model to choose it. [Gemini thought-signature guidance](https://ai.google.dev/gemini-api/docs/generate-content/latest-model), [Anthropic append-only thinking requirements](https://platform.claude.com/docs/en/models/opus-5-5/whats-new-opus-5-5#thinking-blocks-are-tied-to-the-model-and-the-conversation).

## Evidence and limits

Each successful result includes the SDK request, captured HTTP JSON as `wireRequest`, original HTTP response JSON, raw usage, HTTP status, and allowlisted response headers, including provider request IDs and `cf-ray`. Google transforms its SDK `config` object into wire fields such as `generationConfig`; the export reports this explicitly. Request URLs and request headers are never recorded. Error exports sanitize the supplied key and discard the original SDK error object. Browser constructors explicitly opt into browser execution where required.

SDK retry counts are zero (`maxRetries: 0`; Google `attempts: 1` means one total attempt). Caller cancellation and the per-call timeout abort the SDK request. Aborting a local request does not guarantee that the provider stopped generation or billing. Google recommends a substantially longer Argon timeout for long decode tasks; this benchmark's configurable timeout deliberately bounds experiments. [Argon client guidance](https://ai.google.dev/gemini-api/docs/generate-content/latest-model).

A defensive transport counter verifies exactly one HTTP request per observation. `transportAttemptCount` records each custom-fetch invocation on successful results and errors. Any unexpected multi-hop or missing transport capture makes normalized usage unknown, excludes cache/cost metrics, and stops the trial while retaining raw evidence. Older reports without this counter cannot independently establish their HTTP attempt count. Truncation is always reported; replay/append/perturb can retain valid input usage because their subsequent requests do not depend on generated output.

Gemini `promptTokenCount` includes cached input. Its candidate count excludes thoughts, so normalized billable output adds `thoughtsTokenCount` once. [Gemini UsageMetadata definition](https://ai.google.dev/api/generate-content#UsageMetadata).

For a present, otherwise valid usage object, omitted `cachedContentTokenCount` decodes to zero by protocol: Google's public v1beta proto declares `cached_content_token_count` as a plain `int32`, without `optional` or explicit presence, and ProtoJSON omits non-presence fields whose values equal their defaults. This establishes decoding of the reported counter; it makes no assertion about Google's internal cache state. Entirely missing usage, explicit nulls, malformed counters, and impossible cache totals remain unknown. Raw evidence always survives. [Public Google API proto](https://github.com/googleapis/googleapis/blob/master/google/ai/generativelanguage/v1beta/generative_service.proto#L574-L582), [ProtoJSON presence and default values](https://protobuf.dev/programming-guides/json/#presence-and-default-values).

Anthropic output already includes thinking. Where its usage payload does not separately expose a numeric thinking count, exported `thinkingTokens: 0` means unavailable there.

These defaults target the named current models. Overriding a model can change accepted reasoning parameters, cache rules, token accounting, and pricing; inspect exported evidence and update the adapter before drawing conclusions for a different model family. A public alias may resolve to a different version over time; `resolvedModel` records the version when the provider supplies it.
