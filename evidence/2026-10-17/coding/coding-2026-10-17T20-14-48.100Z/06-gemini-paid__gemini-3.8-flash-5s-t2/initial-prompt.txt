# Coding Ledger

Coding Ledger imports supplier invoice CSV files into an integer-cent ledger, detects duplicate or conflicting imports, and optionally reconciles payment files. It is a small, dependency-free accounting utility. Every public result includes the source record number so discrepancies can be traced back to a vendor feed.

Requires Node 22 or newer. There are no packages to install and no network calls.

```sh
node --test test/*.test.mjs
node bin/ledger.mjs import data/invoices.csv --format json
node bin/ledger.mjs import data/invoices.csv --payments data/payments.csv --as-of 2026-03-01
node bin/ledger.mjs schema invoice
```

## Data contract

Invoice columns are `vendor_id,invoice_id,issued_on,due_on,currency,amount,status,description`. The required subset is vendor, invoice, issue date, currency, and amount. Optional due dates default to 30 days after issue; status defaults to `open`; description defaults to empty. Header aliases are declared centrally in `src/schema.mjs`. Unsupported columns are rejected rather than silently ignored.

Amounts are signed decimal major units with up to four fractional digits. Convert them to cents by rounding half away from zero; credits follow the same symmetric rule as invoices. Once parsed, all monetary operations use safe integer cents. Currencies are never mixed or implicitly converted. Date-only values use the ISO calendar and UTC arithmetic.

An invoice number is unique only within its supplier. Vendor identifiers are case-sensitive and trimmed. Invoice identifiers are trimmed and normalized to uppercase. Exact repeated financial rows collapse into one entry; a conflicting row for an existing supplier/invoice identity is diagnosed and the first occurrence retained. Descriptions are not part of financial duplicate identity, so an explanatory wording change does not change totals.

CSV records may end at a newline or at end-of-file. Quoted fields support embedded commas, doubled quotes, and embedded newlines. A final line ending is optional. Empty source records are ignored by the import pipeline. Ragged records become diagnostics instead of being silently truncated.

## Architecture

- `csv.mjs` is a record scanner and writer, independent of accounting semantics.
- `schema.mjs` normalizes headers and validates file shape.
- `validation.mjs` normalizes fields, dates, statuses, currencies, and amounts, collecting all row errors.
- `money.mjs` implements cent parsing, safe arithmetic, formatting, basis points, and deterministic allocation.
- `dates.mjs` provides calendar arithmetic and aging buckets.
- `dedupe.mjs` defines invoice/payment identities and conflict handling.
- `pipeline.mjs` parses and validates whole files before deduplication and report selection.
- `payments.mjs` allocates explicit supplier/invoice payments without currency conversion.
- `ledger.mjs` groups totals, vendors, months, and aging without mutating imported rows.
- `reports.mjs` serializes normalized public records and diagnostics.
- `bin/ledger.mjs` handles argument parsing, file reads, output streams, and exit codes.

Report selection happens after validation and deduplication so filtering cannot conceal malformed or conflicting imports. Payment allocations preserve overpayments as negative outstanding amounts and report unknown invoices, currency mismatches, and post-cutoff payments separately. Paid/void status invoices and credit notes do not absorb new payments.

## Exit and output behavior

The CLI exits 0 after a clean import, 1 for invalid arguments or unreadable/invalid files, and 2 when row conflicts, invalid rows, or unapplied payments remain. Reports are emitted to stdout; curated operational errors go to stderr. JSON output has `schema_version: 1`. The CSV report exports canonical invoice columns plus the source record number; it is an audit export, not a supported re-import format.

Tests exercise the scanner, monetary boundary cases, validation, duplicate identities, payment routing, report totals, and actual CLI subprocess behavior. The supplied vendor feed demonstrates the regressions described in `TASK.md`.

export function parseArgs(args) {
  if (args.includes('--help') || !args.length) return { command: 'help' };
  const [command, file, ...rest] = args;
  if (command === 'schema') {
    if (rest.length || (file && !['invoice','payment'].includes(file))) throw new Error('schema expects invoice or payment');
    return { command, type: file ?? 'invoice' };
  }
  if (command !== 'import' || !file || file.startsWith('--')) throw new Error('Expected import followed by an invoice CSV path');
  const options = { format: 'text' };
  const names = { '--format':'format','--payments':'payments','--vendor':'vendorId','--currency':'currency','--from':'from','--to':'to','--as-of':'asOf','--delimiter':'delimiter' };
  const seen = new Set();
  for (let i = 0; i < rest.length; i += 2) {
    const flag = rest[i], value = rest[i + 1];
    if (!names[flag] || value === undefined || value.startsWith('--')) throw new Error(`Unknown flag or missing value: ${flag}`);
    if (seen.has(flag)) throw new Error(`Repeated option: ${flag}`);
    seen.add(flag);
    options[names[flag]] = value;
  }
  if (!['text','json','csv'].includes(options.format)) throw new Error('format must be text, json, or csv');
  if (options.delimiter && options.delimiter.length !== 1) throw new Error('delimiter must be one character');
  return { command, file, options };
}

/**
 * A small RFC-4180-style reader. A record is an array of strings; callers choose
 * how to interpret headers and values. The scanner is intentionally separate
 * from accounting so imported evidence can be retained without normalization.
 *
 * Rules: commas separate fields outside quotes, doubled quotes represent one
 * quote inside a quoted field, and CRLF/LF/CR terminate unquoted records. Quoted
 * newlines are preserved. A UTF-8 BOM is accepted at the start of a document.
 */
export class CsvError extends Error {
  constructor(message, line, column) {
    super(`${message} at line ${line}, column ${column}`);
    this.name = 'CsvError';
    this.line = line;
    this.column = column;
  }
}

export function parseCsv(input, { delimiter = ',', maxRecords = 100_000 } = {}) {
  if (typeof input !== 'string') throw new TypeError('CSV input must be text');
  if (typeof delimiter !== 'string' || delimiter.length !== 1 || /["\r\n]/.test(delimiter)) {
    throw new TypeError('Delimiter must be one non-quote, non-newline character');
  }
  if (!Number.isSafeInteger(maxRecords) || maxRecords < 1) throw new RangeError('Invalid record limit');
  const text = input.replace(/^\uFEFF/, '');
  const records = [];
  let record = [];
  let field = '';
  let state = 'start';
  let line = 1;
  let column = 0;
  let recordStarted = false;
  const fail = message => { throw new CsvError(message, line, column); };
  const endField = () => { record.push(field); field = ''; state = 'start'; };
  const endRecord = () => {
    endField();
    if (records.length >= maxRecords) fail('CSV exceeds record limit');
    records.push(record);
    record = [];
    recordStarted = false;
  };
  for (let i = 0; i < text.length; i++) {
    const ch = text[i];
    column++;
    if (state === 'quoted') {
      if (ch === '"') state = 'closed';
      else { field += ch; if (ch === '\n') { line++; column = 0; } }
      continue;
    }
    if (state === 'closed' && ch === '"') {
      field += '"';
      state = 'quoted';
      continue;
    }
    if (ch === delimiter) {
      recordStarted = true;
      endField();
      continue;
    }
    if (ch === '\r' || ch === '\n') {
      if (ch === '\r' && text[i + 1] === '\n') i++;
      endRecord();
      line++;
      column = 0;
      continue;
    }
    if (state === 'closed') fail('Unexpected character after closing quote');
    if (ch === '"') {
      if (state !== 'start') fail('Quote inside an unquoted field');
      state = 'quoted';
      recordStarted = true;
      continue;
    }
    field += ch;
    state = 'plain';
    recordStarted = true;
  }
  if (state === 'quoted') fail('Unterminated quoted field');
  // Records are committed by the record-separator branch above.
  return records;
}

export function quoteCsvField(value, delimiter = ',') {
  const text = value == null ? '' : String(value);
  return text.includes(delimiter) || /["\r\n]/.test(text)
    ? `"${text.replaceAll('"', '""')}"` : text;
}

export function stringifyCsv(records, { delimiter = ',', newline = '\n' } = {}) {
  if (!Array.isArray(records) || records.some(record => !Array.isArray(record))) {
    throw new TypeError('CSV records must be arrays');
  }
  if (newline !== '\n' && newline !== '\r\n') throw new TypeError('Unsupported newline');
  return records.map(record => record.map(value => quoteCsvField(value, delimiter)).join(delimiter)).join(newline) + (records.length ? newline : '');
}

/** Preserve source positions instead of silently truncating ragged rows. */
export function csvObjects(records) {
  if (!records.length) return { headers: [], rows: [] };
  const headers = records[0].map(value => value.trim());
  if (new Set(headers).size !== headers.length) throw new Error('Duplicate CSV header');
  if (headers.some(header => !header)) throw new Error('Empty CSV header');
  const rows = records.slice(1).filter(record => record.some(value => value !== '')).map((values, index) => {
    if (values.length !== headers.length) {
      return { sourceRow: index + 2, values, value: null, error: `Expected ${headers.length} fields, received ${values.length}` };
    }
    return { sourceRow: index + 2, values, value: Object.fromEntries(headers.map((header, i) => [header, values[i]])), error: null };
  });
  return { headers, rows };
}

/** Date-only accounting uses UTC calendar arithmetic, never the local timezone. */
export function parseDate(value, field = 'date') {
  const text = String(value).trim();
  const match = /^(\d{4})-(\d{2})-(\d{2})$/.exec(text);
  if (!match) throw new Error(`${field} must use YYYY-MM-DD`);
  const year = Number(match[1]), month = Number(match[2]), day = Number(match[3]);
  if (year < 1900 || year > 2199) throw new Error(`${field} is outside the supported year range`);
  const timestamp = Date.UTC(year, month - 1, day);
  const date = new Date(timestamp);
  if (date.getUTCFullYear() !== year || date.getUTCMonth() !== month - 1 || date.getUTCDate() !== day) throw new Error(`${field} is not a real calendar date`);
  return text;
}

export function dayNumber(value) { return Date.parse(`${parseDate(value)}T00:00:00.000Z`) / 86_400_000; }
export function daysBetween(from, to) { return dayNumber(to) - dayNumber(from); }
export function addDays(value, days) {
  if (!Number.isSafeInteger(days)) throw new TypeError('Day offset must be an integer');
  const date = new Date((dayNumber(value) + days) * 86_400_000);
  return date.toISOString().slice(0, 10);
}
export function monthOf(value) { return parseDate(value).slice(0, 7); }
export function inDateRange(value, from = null, to = null) {
  const date = parseDate(value);
  return (!from || date >= parseDate(from)) && (!to || date <= parseDate(to));
}
export function agingBucket(dueDate, asOf) {
  const lateDays = daysBetween(dueDate, asOf);
  if (lateDays <= 0) return 'current';
  if (lateDays <= 30) return '1-30';
  if (lateDays <= 60) return '31-60';
  if (lateDays <= 90) return '61-90';
  return '90+';
}
export function compareDates(left, right) { return parseDate(left).localeCompare(parseDate(right)); }
export function validatePeriod(from, to) {
  if (from) parseDate(from, 'from');
  if (to) parseDate(to, 'to');
  if (from && to && from > to) throw new Error('Period start must not follow its end');
  return { from: from || null, to: to || null };
}

/**
 * Import identity is local to a supplier. The same invoice number can appear in
 * unrelated suppliers' books. Case normalization occurs before this layer.
 *
 * A repeated identical row is harmless and collapses into its first occurrence.
 * A repeated identity with different financial fields is a conflict: retain the
 * first row and issue a diagnostic rather than silently choosing a winner.
 */
export function invoiceKey(invoice) {
  return invoice.invoiceId;
}
export function paymentKey(payment) { return JSON.stringify([payment.vendorId, payment.paymentId]); }
export function invoiceFingerprint(invoice) {
  return JSON.stringify([invoice.vendorId, invoice.invoiceId, invoice.issuedOn, invoice.dueOn, invoice.currency, invoice.amountCents, invoice.status]);
}
export function paymentFingerprint(payment) {
  return JSON.stringify([payment.vendorId, payment.paymentId, payment.invoiceId, payment.paidOn, payment.currency, payment.amountCents]);
}

export function deduplicate(items, { key, fingerprint, kind }) {
  const first = new Map();
  const accepted = [];
  const duplicates = [];
  const conflicts = [];
  for (const item of items) {
    const identity = key(item);
    const existing = first.get(identity);
    if (!existing) {
      first.set(identity, item);
      accepted.push(item);
      continue;
    }
    const diagnostic = { kind, identity, sourceRow: item.sourceRow, firstSourceRow: existing.sourceRow };
    if (fingerprint(existing) === fingerprint(item)) duplicates.push(diagnostic);
    else conflicts.push({ ...diagnostic, message: `Conflicting ${kind} identity; first occurrence retained` });
  }
  return { accepted, duplicates, conflicts };
}
export function deduplicateInvoices(invoices) {
  return deduplicate(invoices, { key: invoiceKey, fingerprint: invoiceFingerprint, kind: 'invoice' });
}
export function deduplicatePayments(payments) {
  return deduplicate(payments, { key: paymentKey, fingerprint: paymentFingerprint, kind: 'payment' });
}
export function indexInvoices(invoices) {
  const index = new Map();
  for (const invoice of invoices) {
    const key = invoiceKey(invoice);
    if (index.has(key)) throw new Error('Cannot index unresolved duplicate invoices');
    index.set(key, invoice);
  }
  return index;
}
export function groupByVendor(items) {
  const groups = new Map();
  for (const item of items) {
    const group = groups.get(item.vendorId) ?? [];
    group.push(item);
    groups.set(item.vendorId, group);
  }
  return groups;
}

import { addCents, sumMoneyBy } from './money.mjs';
import { agingBucket, inDateRange, monthOf, parseDate, validatePeriod } from './dates.mjs';
import { groupByVendor } from './dedupe.mjs';

/** Reporting filters do not mutate the imported source ledger. */
export function selectInvoices(invoices, { vendorId = null, currency = null, from = null, to = null, includeVoid = false } = {}) {
  validatePeriod(from, to);
  return invoices.filter(invoice =>
    (!vendorId || invoice.vendorId === vendorId) &&
    (!currency || invoice.currency === currency) &&
    (includeVoid || invoice.status !== 'void') &&
    inDateRange(invoice.issuedOn, from, to));
}

export function summarizeInvoices(invoices) {
  const currencies = new Map();
  for (const invoice of invoices) {
    const total = currencies.get(invoice.currency) ?? {
      currency: invoice.currency, invoiceCount: 0, totalCents: 0, openCents: 0,
      paidCents: 0, creditCents: 0, voidCount: 0,
    };
    total.invoiceCount++;
    if (invoice.status === 'void') { total.voidCount++; currencies.set(invoice.currency, total); continue; }
    total.totalCents = addCents(total.totalCents, invoice.amountCents);
    if (invoice.amountCents < 0) total.creditCents = addCents(total.creditCents, invoice.amountCents);
    if (invoice.status === 'paid') total.paidCents = addCents(total.paidCents, invoice.amountCents);
    else total.openCents = addCents(total.openCents, invoice.amountCents);
    currencies.set(invoice.currency, total);
  }
  return [...currencies.values()].sort((a, b) => a.currency.localeCompare(b.currency));
}

export function vendorSummary(invoices) {
  return [...groupByVendor(invoices)].sort(([a], [b]) => a.localeCompare(b)).map(([vendorId, group]) => ({
    vendorId, invoiceCount: group.length, currencies: summarizeInvoices(group),
    earliestIssue: group.reduce((min, invoice) => invoice.issuedOn < min ? invoice.issuedOn : min, group[0].issuedOn),
    latestIssue: group.reduce((max, invoice) => invoice.issuedOn > max ? invoice.issuedOn : max, group[0].issuedOn),
  }));
}

export function monthlySummary(invoices) {
  const groups = new Map();
  for (const invoice of invoices) {
    const month = monthOf(invoice.issuedOn);
    const group = groups.get(month) ?? [];
    group.push(invoice);
    groups.set(month, group);
  }
  return [...groups].sort(([a], [b]) => a.localeCompare(b)).map(([month, group]) => ({ month, currencies: summarizeInvoices(group) }));
}

export function agingSummary(entries, asOf) {
  parseDate(asOf, 'asOf');
  const totals = new Map();
  for (const entry of entries) {
    if (entry.outstandingCents <= 0 || entry.invoice.status === 'void') continue;
    const bucket = agingBucket(entry.invoice.dueOn, asOf);
    const key = JSON.stringify([entry.invoice.currency, bucket]);
    const group = totals.get(key) ?? { currency: entry.invoice.currency, bucket, count: 0, outstandingCents: 0 };
    group.count++;
    group.outstandingCents = addCents(group.outstandingCents, entry.outstandingCents);
    totals.set(key, group);
  }
  const bucketOrder = ['current', '1-30', '31-60', '61-90', '90+'];
  return [...totals.values()].sort((a, b) => a.currency.localeCompare(b.currency) || bucketOrder.indexOf(a.bucket) - bucketOrder.indexOf(b.bucket));
}

export function outstandingByVendor(entries) {
  return sumMoneyBy(entries, entry => JSON.stringify([entry.invoice.vendorId, entry.invoice.currency]), entry => entry.outstandingCents)
    .map(({ key, cents }) => { const [vendorId, currency] = JSON.parse(key); return { vendorId, currency, outstandingCents: cents }; });
}

/** Money stays in integer minor units once it enters the ledger. */
export class MoneyError extends Error {
  constructor(message) { super(message); this.name = 'MoneyError'; }
}

/**
 * Parse signed decimal major units into cents. Vendor feeds may contain up to
 * four fractional digits. The business rule is round half away from zero at
 * the cent boundary (1.005 => 101; -1.005 => -101), not bankers' rounding.
 * Group separators and scientific notation are deliberately unsupported.
 */
export function parseMoney(value) {
  const text = String(value).trim();
  if (!/^[+-]?\d+(?:\.\d{1,4})?$/.test(text)) throw new MoneyError('Expected a decimal amount with at most four fractional digits');
  const cents = Math.round(Number(text) * 100);
  if (!Number.isSafeInteger(cents)) throw new MoneyError('Amount exceeds safe integer range');
  return Object.is(cents, -0) ? 0 : cents;
}

export function assertCents(value) {
  if (!Number.isSafeInteger(value)) throw new MoneyError('Money must be integer cents');
  return value;
}

export function addCents(...values) {
  return values.reduce((sum, value) => {
    assertCents(value);
    const next = sum + value;
    if (!Number.isSafeInteger(next)) throw new MoneyError('Money total exceeds safe integer range');
    return next;
  }, 0);
}

export function subtractCents(left, right) { return addCents(left, -assertCents(right)); }

export function formatMoney(cents, { currency = 'USD', withCurrency = false } = {}) {
  assertCents(cents);
  const sign = cents < 0 ? '-' : '';
  const magnitude = Math.abs(cents);
  const decimal = `${sign}${Math.floor(magnitude / 100)}.${String(magnitude % 100).padStart(2, '0')}`;
  return withCurrency ? `${currency} ${decimal}` : decimal;
}

/** Largest-remainder allocation preserves the exact total and stable tie order. */
export function allocateCents(cents, weights) {
  assertCents(cents);
  if (!Array.isArray(weights) || !weights.length || weights.some(w => !Number.isSafeInteger(w) || w < 0)) {
    throw new MoneyError('Allocation weights must be nonnegative integers');
  }
  const weightTotal = weights.reduce((sum, weight) => sum + BigInt(weight), 0n);
  if (weightTotal === 0n) throw new MoneyError('Allocation needs a positive total weight');
  const magnitude = BigInt(Math.abs(cents));
  const parts = weights.map((weight, index) => ({ index, base: magnitude * BigInt(weight) / weightTotal, remainder: magnitude * BigInt(weight) % weightTotal }));
  let left = magnitude - parts.reduce((sum, part) => sum + part.base, 0n);
  const order = [...parts].sort((a, b) => a.remainder === b.remainder ? a.index - b.index : a.remainder > b.remainder ? -1 : 1);
  for (const part of order) { if (left === 0n) break; part.base++; left--; }
  const sign = cents < 0 ? -1 : 1;
  return parts.map(part => sign * Number(part.base));
}

/** Integer basis points avoid floating-point percentage drift. */
export function applyBasisPoints(cents, basisPoints) {
  assertCents(cents);
  if (!Number.isSafeInteger(basisPoints)) throw new MoneyError('Basis points must be integers');
  const product = BigInt(cents) * BigInt(basisPoints);
  const sign = product < 0n ? -1n : 1n;
  const magnitude = product < 0n ? -product : product;
  const rounded = sign * ((magnitude + 5000n) / 10000n);
  const result = Number(rounded);
  return assertCents(result);
}

export function sumMoneyBy(items, selectKey, selectCents) {
  const totals = new Map();
  for (const item of items) {
    const key = selectKey(item);
    totals.set(key, addCents(totals.get(key) ?? 0, selectCents(item)));
  }
  return [...totals].sort(([a], [b]) => String(a).localeCompare(String(b))).map(([key, cents]) => ({ key, cents }));
}

import { addCents, subtractCents } from './money.mjs';
import { indexInvoices, invoiceKey } from './dedupe.mjs';

/**
 * Payments are never implicitly converted between currencies. Every allocation
 * names the invoice and supplier explicitly. Unknown invoices and overpayments
 * stay visible in the reconciliation result for a human to investigate.
 */
export function reconcilePayments(invoices, payments, { asOf = null } = {}) {
  const index = indexInvoices(invoices);
  const balances = new Map(invoices.map(invoice => [invoiceKey(invoice), {
    invoice,
    originalCents: invoice.status === 'void' ? 0 : invoice.amountCents,
    paidCents: invoice.status === 'paid' ? invoice.amountCents : 0,
    paymentIds: [],
  }]));
  const applied = [];
  const unapplied = [];
  for (const payment of [...payments].sort((a, b) => a.paidOn.localeCompare(b.paidOn) || a.sourceRow - b.sourceRow)) {
    const key = invoiceKey(payment);
    const invoice = index.get(key);
    let reason = null;
    if (asOf && payment.paidOn > asOf) reason = 'after-as-of';
    else if (!invoice) reason = 'unknown-invoice';
    else if (invoice.currency !== payment.currency) reason = 'currency-mismatch';
    else if (invoice.status === 'void') reason = 'void-invoice';
    else if (invoice.status === 'paid') reason = 'already-paid-status';
    else if (invoice.amountCents <= 0) reason = 'credit-invoice';
    if (reason) { unapplied.push({ payment, reason }); continue; }
    const balance = balances.get(key);
    balance.paidCents = addCents(balance.paidCents, payment.amountCents);
    balance.paymentIds.push(payment.paymentId);
    applied.push({ paymentId: payment.paymentId, vendorId: payment.vendorId, invoiceId: payment.invoiceId, amountCents: payment.amountCents });
  }
  const entries = [...balances.values()].map(balance => ({
    ...balance,
    outstandingCents: subtractCents(balance.originalCents, balance.paidCents),
    overpaymentCents: Math.max(0, balance.paidCents - Math.max(0, balance.originalCents)),
  }));
  return { entries, applied, unapplied };
}

export function paymentSummary(reconciliation) {
  const totals = new Map();
  for (const entry of reconciliation.entries) {
    const currency = entry.invoice.currency;
    const value = totals.get(currency) ?? { currency, invoicedCents: 0, paidCents: 0, outstandingCents: 0, overpaymentCents: 0 };
    value.invoicedCents = addCents(value.invoicedCents, entry.originalCents);
    value.paidCents = addCents(value.paidCents, entry.paidCents);
    value.outstandingCents = addCents(value.outstandingCents, entry.outstandingCents);
    value.overpaymentCents = addCents(value.overpaymentCents, entry.overpaymentCents);
    totals.set(currency, value);
  }
  return [...totals.values()].sort((a, b) => a.currency.localeCompare(b.currency));
}

import { parseCsv } from './csv.mjs';
import { inspectHeaders, projectColumns } from './schema.mjs';
import { validateInvoice, validatePayment, flattenValidationErrors } from './validation.mjs';
import { deduplicateInvoices, deduplicatePayments } from './dedupe.mjs';
import { monthlySummary, selectInvoices, summarizeInvoices, vendorSummary, agingSummary, outstandingByVendor } from './ledger.mjs';
import { paymentSummary, reconcilePayments } from './payments.mjs';

/** Parse and validate complete files before applying accounting or report filters. */
function readRows(text, type, options) {
  const records = parseCsv(text, { delimiter: options.delimiter ?? ',', maxRecords: options.maxRecords ?? 100_000 });
  if (!records.length) throw new Error(`Empty ${type} CSV`);
  const { normalized, errors } = inspectHeaders(records[0], { type, rejectUnknown: options.rejectUnknown ?? true });
  if (errors.length) throw new Error(errors.join('; '));
  const good = [];
  const diagnostics = [];
  let sourceRows = 0;
  records.slice(1).forEach((values, index) => {
    if (values.every(value => value.trim() === '')) return;
    sourceRows++;
    const sourceRow = index + 2;
    try {
      const raw = projectColumns(values, normalized);
      const validation = type === 'invoice' ? validateInvoice(raw, sourceRow) : validatePayment(raw, sourceRow);
      const value = type === 'invoice' ? validation.invoice : validation.payment;
      if (value) good.push(value);
      else diagnostics.push(...flattenValidationErrors([validation]).map(error => ({ kind: 'validation', ...error })));
    } catch (error) { diagnostics.push({ kind: 'shape', sourceRow, message: error.message }); }
  });
  return { good, diagnostics, sourceRows };
}

export function importInvoices(text, options = {}) {
  const parsed = readRows(text, 'invoice', options);
  const deduped = deduplicateInvoices(parsed.good);
  const diagnostics = [...parsed.diagnostics, ...deduped.conflicts.map(conflict => ({ ...conflict, kind: 'conflict' }))];
  const invoices = selectInvoices(deduped.accepted, { ...options, includeVoid: options.includeVoid ?? true });
  const rejectedRows = new Set(parsed.diagnostics.map(error => error.sourceRow));
  return {
    source: options.source ?? '(memory)', invoices,
    counts: { sourceRows: parsed.sourceRows, accepted: deduped.accepted.length, selected: invoices.length,
      rejected: rejectedRows.size, duplicates: deduped.duplicates.length, conflicts: deduped.conflicts.length },
    totals: summarizeInvoices(invoices), vendors: vendorSummary(invoices), months: monthlySummary(invoices),
    diagnostics, duplicates: deduped.duplicates, reconciliation: null,
  };
}

export function importPayments(text, options = {}) {
  const parsed = readRows(text, 'payment', options);
  const deduped = deduplicatePayments(parsed.good);
  return { payments: deduped.accepted, duplicates: deduped.duplicates,
    diagnostics: [...parsed.diagnostics, ...deduped.conflicts.map(conflict => ({ ...conflict, kind: 'payment-conflict' }))],
    sourceRows: parsed.sourceRows };
}

export function importAndReconcile(invoiceText, paymentText, options = {}) {
  const imported = importInvoices(invoiceText, options);
  const paymentImport = importPayments(paymentText, options);
  const reconciliation = reconcilePayments(imported.invoices, paymentImport.payments, { asOf: options.asOf ?? null });
  imported.diagnostics.push(...paymentImport.diagnostics,
    ...reconciliation.unapplied.map(item => ({ kind: 'unapplied-payment', sourceRow: item.payment.sourceRow, message: `Payment ${item.payment.paymentId}: ${item.reason}` })));
  imported.reconciliation = {
    appliedCount: reconciliation.applied.length, unappliedCount: reconciliation.unapplied.length,
    totals: paymentSummary(reconciliation), outstandingByVendor: outstandingByVendor(reconciliation.entries),
    aging: options.asOf ? agingSummary(reconciliation.entries, options.asOf) : null,
    unapplied: reconciliation.unapplied.map(item => ({ paymentId: item.payment.paymentId, vendorId: item.payment.vendorId, reason: item.reason })),
  };
  return imported;
}

export const INVOICE_COLUMNS = Object.freeze([
  'vendor_id', 'invoice_id', 'issued_on', 'due_on', 'currency', 'amount', 'status', 'description',
]);
export const PAYMENT_COLUMNS = Object.freeze(['payment_id', 'vendor_id', 'invoice_id', 'paid_on', 'currency', 'amount']);
export const REQUIRED_INVOICE_COLUMNS = Object.freeze(['vendor_id', 'invoice_id', 'issued_on', 'currency', 'amount']);
export const REQUIRED_PAYMENT_COLUMNS = Object.freeze([...PAYMENT_COLUMNS]);
export const CURRENCIES = Object.freeze(['USD', 'EUR', 'GBP', 'CAD', 'AUD']);
export const STATUSES = Object.freeze(['open', 'paid', 'void']);
export const HEADER_ALIASES = Object.freeze({ vendor: 'vendor_id', supplier: 'vendor_id', invoice: 'invoice_id', invoice_date: 'issued_on', due_date: 'due_on', total: 'amount', notes: 'description' });

export function normalizeHeader(header) {
  const key = String(header).trim().toLowerCase().replace(/[ -]+/g, '_');
  return HEADER_ALIASES[key] ?? key;
}
export function inspectHeaders(headers, { type = 'invoice', rejectUnknown = true } = {}) {
  const allowed = type === 'payment' ? PAYMENT_COLUMNS : INVOICE_COLUMNS;
  const required = type === 'payment' ? REQUIRED_PAYMENT_COLUMNS : REQUIRED_INVOICE_COLUMNS;
  const normalized = headers.map(normalizeHeader);
  const errors = [];
  for (const name of required) if (!normalized.includes(name)) errors.push(`Missing required column: ${name}`);
  for (const name of new Set(normalized)) if (normalized.filter(value => value === name).length > 1) errors.push(`Columns normalize to the same name: ${name}`);
  if (rejectUnknown) for (const name of normalized) if (!allowed.includes(name)) errors.push(`Unknown column: ${name}`);
  return { normalized, errors };
}
export function projectColumns(values, headers) {
  if (values.length !== headers.length) throw new Error(`Expected ${headers.length} fields, received ${values.length}`);
  return Object.fromEntries(headers.map((name, i) => [name, values[i]]));
}
export function publicSchema(type = 'invoice') {
  const columns = type === 'payment' ? PAYMENT_COLUMNS : INVOICE_COLUMNS;
  const required = type === 'payment' ? REQUIRED_PAYMENT_COLUMNS : REQUIRED_INVOICE_COLUMNS;
  return columns.map(name => ({ name, required: required.includes(name), kind: name.endsWith('_on') ? 'date' : name === 'amount' ? 'decimal' : 'text' }));
}

import { parseMoney } from './money.mjs';
import { addDays, parseDate } from './dates.mjs';
import { CURRENCIES, STATUSES } from './schema.mjs';

export function identifier(value, field) {
  const text = String(value ?? '').trim();
  if (!text || text.length > 80 || /[\x00-\x1f\x7f]/.test(text)) throw new Error(`${field} must be 1-80 printable characters`);
  return text;
}
export function normalizeInvoiceId(value) {
  // Supplier invoice identifiers are case-insensitive; vendor identifiers are not.
  return identifier(value, 'invoice_id').toUpperCase();
}
export function currencyCode(value) {
  const code = String(value ?? '').trim().toUpperCase();
  if (!CURRENCIES.includes(code)) throw new Error(`Unsupported currency: ${code || '(empty)'}`);
  return code;
}
function get(row, key, fallback = '') { return row[key] === undefined || row[key] === '' ? fallback : row[key]; }

/** One invalid row is reported without dropping valid peers from the import. */
export function validateInvoice(row, sourceRow) {
  const errors = [];
  const result = { sourceRow };
  const attempt = (name, operation) => { try { result[name] = operation(); } catch (error) { errors.push({ field: name, message: error.message }); } };
  attempt('vendorId', () => identifier(row.vendor_id, 'vendor_id'));
  attempt('invoiceId', () => normalizeInvoiceId(row.invoice_id));
  attempt('issuedOn', () => parseDate(row.issued_on, 'issued_on'));
  attempt('dueOn', () => get(row, 'due_on') ? parseDate(row.due_on, 'due_on') : addDays(parseDate(row.issued_on), 30));
  attempt('currency', () => currencyCode(row.currency));
  attempt('amountCents', () => parseMoney(row.amount));
  attempt('status', () => {
    const status = String(get(row, 'status', 'open')).trim().toLowerCase();
    if (!STATUSES.includes(status)) throw new Error('status must be open, paid, or void');
    return status;
  });
  attempt('description', () => {
    const description = String(get(row, 'description')).trim();
    if (description.length > 1000 || /[\x00\x7f]/.test(description)) throw new Error('description is too long or contains control characters');
    return description;
  });
  if (result.issuedOn && result.dueOn && result.dueOn < result.issuedOn) errors.push({ field: 'dueOn', message: 'due_on precedes issued_on' });
  return errors.length ? { sourceRow, invoice: null, errors } : { sourceRow, invoice: Object.freeze(result), errors: [] };
}

export function validatePayment(row, sourceRow) {
  const errors = [];
  const result = { sourceRow };
  for (const [field, action] of [
    ['paymentId', () => identifier(row.payment_id, 'payment_id')],
    ['vendorId', () => identifier(row.vendor_id, 'vendor_id')],
    ['invoiceId', () => normalizeInvoiceId(row.invoice_id)],
    ['paidOn', () => parseDate(row.paid_on, 'paid_on')],
    ['currency', () => currencyCode(row.currency)],
    ['amountCents', () => { const cents = parseMoney(row.amount); if (cents <= 0) throw new Error('Payment amount must be positive'); return cents; }],
  ]) {
    try { result[field] = action(); } catch (error) { errors.push({ field, message: error.message }); }
  }
  return errors.length ? { sourceRow, payment: null, errors } : { sourceRow, payment: Object.freeze(result), errors: [] };
}

export function flattenValidationErrors(validations) {
  return validations.flatMap(row => row.errors.map(error => ({ sourceRow: row.sourceRow, ...error })));
}
export function describeErrors(errors) { return errors.map(error => `row ${error.sourceRow} / ${error.field}: ${error.message}`).join('\n'); }
