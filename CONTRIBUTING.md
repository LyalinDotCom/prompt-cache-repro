# Feedback

Cachebench is an unofficial community project. It is not affiliated with or endorsed by any model provider. Results are experimental, may contain measurement or interpretation errors, and are not guaranteed to be accurate.

Feedback, bug reports, methodology corrections, and reproducible observations are welcome through GitHub issues. Include the model, workload, key/account label (never the key itself), actual timing, and the smallest relevant redacted report. Do not post API keys, private prompts, billing details, or other confidential information.

We do not accept pull requests. Please describe the proposed correction or improvement in an issue instead. Maintainer changes are committed directly to `main`.

The source is licensed under Apache 2.0. Repository access is private for now; the license does not change who has repository access.
